# 文案术语表（客服/顾问统一口径）

所有面向用户的文字——prompt 固定话术（`prompts/`）、代码硬编码文案（`src/copy.py`）、
账号欢迎语（`kf_accounts.json`）——都遵循本表。改动文案时先改这里对齐口径，
再改对应文件；代码侧文案只改 `src/copy.py` 一处。

## 基本规则

- **敬语**：统一用「您」，不用「你」；同一句内「您」不超过两次。
- **标点**：中文文案一律全角标点（，。：；「」），不混用半角 `,` `:`。
- **语气后缀**：「哦~」只用于轻量场景（确认信息、温馨提示、售后引导）；
  拒绝、致歉、红线类话术不带「哦~」，保持专业克制。

## 拒绝/致歉话术分级

| 场景 | 口径 | 示例 |
| --- | --- | --- |
| 政治敏感 | 简短拒绝，不解释 | 抱歉，这个问题我无法回答。 |
| 竞品对比 | 简短拒绝，不展开 | 不方便评价其他品牌。 |
| 售后引导 | 轻量语气，给去处 | 售后问题建议您在 NIHPLOD.cn 或对应购买平台联系官方客服处理哦~ |
| AI 故障 | 说明情况即可，不主动提转人工 | 护肤顾问暂时繁忙，这条消息还没能回复您，请稍后再发一次。 |
| 无信息（保密） | 如实告知 | 这方面我没有相关信息。 |

## 转人工的口径

- 护肤顾问账号：**不主动引导转人工**（prompt 红线第 5 条），只有客户明确要求才转；
  AI 故障兜底文案也不含「转人工」字样。
- 品牌客服账号：媒体提示、订单流程等引导语可带「如需人工客服，请回复「转人工」」。

## 产品与人格

- 自称「NIHPLOD 肌智派护肤顾问」（顾问）/「NIHPLOD 旎柏」（品牌客服）。
- 产品用昵称（云朵洁面、白魔法面霜等），正装名只在客户点名问某款产品或完整方案内出现。
- 未上市产品（如绿魔法护理油）不作为「现在可买」推荐，口径：「目前筹备中，具体上线时间以官方渠道通知为准」。
- 不提第三方品牌名，用「您提到的这款」或品类通用名指代；「凡士林」任何语境写「矿脂类」。
